# PRC Nexus Self Improving Guidelines

> Canonical docs: [docs/plugins/prc-nexus-self-improving-guidelines/](../../docs/plugins/prc-nexus-self-improving-guidelines/)

Harvests Gutenberg editor notes after publish, proposes generalizable editorial memories, and lets editors inject approved rules into Settings → Guidelines.

## Development

```bash
npx turbo build --filter=@prc/nexus-self-improving-guidelines
```
